# Course Registration System Java

## Description:
The Course Registration System is a Java-based mini project that allows students to log in, view available courses, register for courses, check seat availability, view registered courses, and drop courses. This project demonstrates Object-Oriented Programming concepts such as classes, objects, inheritance, abstraction, encapsulation, polymorphism, and ArrayList.

## Features
--> Student Login
--> View Available Courses
--> Register for Course
--> Check Seat Availability
--> View Registered Courses
--> Drop Course
--> Search Course
--> Prevent Duplicate Registration
--> Logout

## Technologies Used
- Java
- ArrayList
- VS Code
